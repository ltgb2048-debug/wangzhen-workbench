# 15天公考小白进阶工具

这是一个**个人自学用的本地网页版训练工具**，目标是帮助零基础用户在15天内建立对以下三类考试的基础认知，并具备基础咨询与筛岗思维：

- 国考
- 内蒙古省考
- 内蒙古事业单位

## 当前版本定位

V0.1 先做“能每天用”的个人学习闭环：

1. 今日学习
2. 考考我
3. 模拟咨询
4. 公考百科
5. 我的进度

全部数据默认保存在浏览器 `localStorage`，不依赖服务器。

> 注意：具体招考政策、报名时间、岗位条件、考试节点等会变化。当前版本只放稳定的基础框架；后续将以用户提供的内部培训资料、课程体系和官方资料为准补充和校准。

## 使用方法

直接双击 `index.html` 即可在浏览器打开。

建议使用 Chrome / Edge。

## 15天学习路线

- 第1—3天：公考全景、考试类型、招考流程与术语
- 第4—6天：国考、内蒙古省考、内蒙古事业单位基础
- 第7—9天：岗位表字段、筛岗逻辑、筛岗实战
- 第10—11天：课程体系与课程匹配（等待导入内部资料）
- 第12—13天：咨询开场、需求挖掘、异议处理
- 第14天：综合模拟咨询
- 第15天：综合考核

## 后续准备补充

等内部资料整理完成后，优先补充：

- 课程体系
- 国考/内蒙古省考/事业单位考情资料
