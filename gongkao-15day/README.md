# 15天公考小白进阶工具

这是一个**个人自学用的本地网页版训练工具**，目标不是在15天内“变成真正专家”，而是让零基础用户建立公考框架，并能独立完成基础咨询、知道什么时候需要查公告/岗位表。

当前重点：

- 国考
- 内蒙古省考
- 内蒙古事业单位

## 当前版本：V0.2

已升级为“学习 + 测验 + 咨询模拟 + 进度复盘”的个人训练闭环：

1. 今日学习
2. 随机10题测验
3. 模拟咨询
4. 公考百科
5. 我的进度 / 上岗准备度

全部数据默认保存在浏览器 `localStorage`，不依赖服务器。

## 资料来源原则

当前训练内容优先依据用户提供的内部资料整理：

- 《内蒙古考试一本通【2024-2025版】》
- 《内蒙古报考常见问题》
- 《呼市校区学员服务中心规章制度（2025年11月）》
- 2026、2027年度内蒙古自治区事业单位岗位表（后续用于真实筛岗训练）

### 重要边界

资料中同时存在“稳定知识”和“历史年份政策”。

- 稳定知识：考试体系、流程、科目概念、事业单位ABCDE分类、咨询方法等，可用于学习训练。
- 时效知识：报名时间、年龄、户籍、加分、成绩比例、开考比例、具体岗位条件等，只作为历史参考。

工具中遇到时效性问题时，统一要求回到**当年官方公告、岗位表或招录机关口径**核实，避免把旧年份规则当成现行政策。

## 15天学习路线

- 第1天：公考全景图
- 第2天：完整招录流程
- 第3天：行测 / 申论 / 职测 / 综应
- 第4天：国考基础咨询
- 第5天：内蒙古省考基础咨询
- 第6天：内蒙古事业单位ABCDE
- 第7天：岗位表字段识别
- 第8天：信息不足判断
- 第9天：真实岗位表筛岗
- 第10天：课程体系与学习阶段
- 第11天：学员画像与需求挖掘
- 第12天：报名期高频问题门诊
- 第13天：完整咨询
- 第14天：异议与课程建议
- 第15天：综合毕业考

## 使用方法

直接双击 `index.html` 即可在浏览器打开。

建议使用 Chrome / Edge。
